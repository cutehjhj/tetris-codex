# Tetris Codex

순수 HTML·CSS·JavaScript로 만든 싱글 플레이어 테트리스 게임입니다. 설치나 로그인 없이 브라우저에서 바로 플레이할 수 있으며, 프레임워크와 빌드 도구를 사용하지 않습니다.

## 데모

**GitHub Pages 데모:** `<여기에링크>`

GitHub Pages 배포 후 위 자리를 실제 데모 주소로 교체해주세요.

## 게임 소개

- 10 × 20 보드와 7종 테트로미노(I, O, T, S, Z, J, L)
- 자동 하강, 좌우 이동, 시계 방향 회전, Soft Drop, Hard Drop
- 완성된 여러 줄의 동시 삭제와 점수 누적
- 다음 블록 미리보기와 점수에 따른 레벨·속도 증가
- 게임오버 안내와 다시 시작
- 화면 폭에 맞춰 크기가 조절되는 보드

새 블록을 생성할 공간이 없으면 게임이 종료됩니다. **다시 시작** 버튼을 누르면 보드·점수·레벨이 초기화되고 새 게임이 시작됩니다.

## 실행 방법

1. 이 저장소를 다운로드하거나 클론합니다.
2. 프로젝트 폴더의 `index.html`을 더블클릭해 브라우저에서 엽니다.
3. 페이지가 열리면 게임이 자동으로 시작됩니다.

게임 실행에는 패키지 설치, 서버 실행, 빌드 과정이 필요하지 않습니다. 키보드가 있는 데스크톱 환경을 권장합니다. 작은 화면에서도 보드는 축소되지만 모바일 터치 조작은 제공하지 않습니다.

## 조작법

| 키 / 버튼 | 동작 |
| --- | --- |
| ← | 왼쪽으로 한 칸 이동 |
| → | 오른쪽으로 한 칸 이동 |
| ↑ | 시계 방향으로 회전 |
| ↓ | 한 칸 빠르게 하강(Soft Drop). 누르고 있으면 반복 하강 |
| Space(스페이스바) | 가능한 가장 아래 위치로 즉시 하강하고 고정(Hard Drop) |
| 다시 시작 | 보드·점수·레벨을 초기화하고 새 게임 시작 |

벽이나 고정 블록에 막히는 이동·회전은 적용되지 않습니다. 회전 시 별도의 벽 보정 이동은 하지 않습니다.

## 점수와 레벨

| 한 번에 삭제한 줄 수 | 추가 점수 |
| --- | ---: |
| 1줄 | 100점 |
| 2줄 | 300점 |
| 3줄 | 500점 |
| 4줄 | 800점 |

점수는 줄 삭제로 누적되며, Soft Drop과 Hard Drop 자체에는 추가 점수가 없습니다.

- 시작 레벨은 1이며, 누적 점수 1,000점마다 레벨이 1씩 올라갑니다.
- 자동 하강 간격은 500ms에서 시작해 레벨마다 40ms씩 줄어듭니다.
- 가장 빠른 자동 하강 간격은 100ms입니다.

## 프로젝트 구조

```text
index.html          # 게임 화면과 캔버스
style.css           # 화면 스타일과 반응형 배치
script.js           # 게임 상태, 규칙, 렌더링, 키보드 입력
tests/playtest.cjs   # Chrome·Edge 브라우저 검증
PRD.md              # 제품 요구사항
MVP-TODO.md         # 초기 구현 계획과 완료기준
.agents/skills/     # 품질관리 skill
```

## 개발 검증

Playwright를 Node.js에서 불러올 수 있고 Chrome·Edge가 설치된 개발 환경에서 실행합니다. 이 도구들은 게임 플레이에는 필요하지 않습니다.

```sh
node tests/playtest.cjs
```

요구사항은 [PRD.md](./PRD.md), 초기 작업 계획은 [MVP-TODO.md](./MVP-TODO.md)를 참고하세요. 초기 계획의 체크박스는 현재 구현 상태를 자동으로 반영하지 않습니다.
