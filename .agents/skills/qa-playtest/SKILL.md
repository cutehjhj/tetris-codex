# 사용자 시나리오 QA

## 수행 절차

1. 저장소 지침, PRD, README의 실행법·키 배치·확정 점수 규칙을 확인한다.
2. 브라우저 버전과 실행 환경을 기록하고 각 시나리오의 초기 상태, 재현 절차, 기대 결과, 실제 결과를 남긴다.
3. 지정된 블록 순서나 테스트 보드가 필요하면 기존 테스트 장치를 사용한다. 재현을 위해 제품 코드를 직접 수정하지 않는다.

## 점검 체크리스트

- [ ] 첫 실행: 통과 — 설치·로그인 요구 없이 페이지에서 10 × 20 보드, 점수 0, 활성 블록과 자동 하강을 확인한다. 실패 — 시작이 막히거나 초기 상태가 다르다.
- [ ] 이동: 통과 — 좌우 입력이 즉시 반영되고 벽·고정 셀을 넘지 않는다. 실패 — 입력 누락, 잘못된 이동 또는 관통이 발생한다.
- [ ] 회전: 통과 — 회전 키가 확정된 방향으로 동작하고 막힌 회전은 정책대로 처리한다. 실패 — 잘못된 형태나 충돌 배치가 표시된다.
- [ ] Soft Drop: 통과 — 입력 시 자동 하강 주기를 기다리지 않고 규칙대로 내려가며 막히면 한 번 고정된다. 실패 — 반응이 없거나 중복 고정된다.
- [ ] 고정 후 진행: 통과 — 바닥·고정 셀 위에서 정확히 고정되고 다음 블록이 생성된다. 실패 — 위치가 잘못되거나 진행이 중단된다.
- [ ] 줄 제거와 점수: 통과 — 1/2/3/4줄 제거가 확정된 점수와 일치하고 누적된다(제안 규칙 채택 시 100/300/500/800점, 4줄은 800점). 실패 — 줄 수·점수·누적값이 다르다.
- [ ] Game Over: 통과 — 생성 위치가 막히면 종료 안내가 나타나고 입력·자동 하강이 멈춘다. 실패 — 종료하지 않거나 종료 후 상태가 변한다.
- [ ] 종료 후 Restart: 통과 — 버튼으로 보드·점수·종료 상태를 초기화하고 새 블록으로 다시 진행한다. 실패 — 이전 상태가 남거나 다시 시작하지 않는다.
- [ ] 진행 중 반복 Restart: 통과 — 여러 번 재시작해도 입력이 한 번만 적용되고 정상 간격으로 하강한다. 실패 — 이벤트·루프 중복 또는 즉시 하강이 발생한다.
- [ ] 데스크톱 브라우저: 통과 — 검증 대상 Chrome·Edge·Firefox에서 필수 시나리오가 모두 성공한다. 실패 — 특정 브라우저에서 재현 가능한 동작 오류가 있다.

## 보고 규칙

코드를 직접 고치지 않는다. 각 시나리오를 통과/실패로 기록하고 미실행·재현 불가 항목은 미검증으로 구분한다.

문제는 `항목 | 심각도(높음·중간·낮음) | 개선안` 표로 보고한다. 항목에 재현 절차와 기대·실제 결과를 포함한다. 높음은 플레이·재시작 불가 또는 상태 손상, 중간은 특정 조작·점수·표시 오류, 낮음은 진행을 막지 않는 사용성 문제다. 문제가 없으면 그 사실과 미검증 범위를 적는다.
