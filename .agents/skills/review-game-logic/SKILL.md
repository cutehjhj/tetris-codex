# 게임 로직 검토

## 수행 절차

1. 저장소 지침, PRD, 확정된 게임 규칙과 핵심 로직 테스트를 읽는다.
2. 아래 사례를 기존 테스트나 임시 실행으로 검증하되 저장소 코드를 직접 변경하지 않는다.
3. 규칙이 미정인 항목은 확인 필요로 표시하고 임의 규칙을 요구사항으로 취급하지 않는다.

## 점검 체크리스트

- [ ] 보드 경계: 통과 — 10 × 20 보드에서 유효 셀은 허용하고 좌우·상단·바닥 밖의 배치는 확정 규칙대로 거부한다. 실패 — 경계 밖 접근이나 유효 배치의 잘못된 거부가 발생한다.
- [ ] 고정 셀 충돌: 통과 — 네 셀 중 하나라도 겹치면 이동을 거부하고 인접 셀은 허용한다. 실패 — 겹침을 허용하거나 인접 배치를 충돌로 판단한다.
- [ ] 이동 실패: 통과 — 거부된 이동·회전은 원래 블록 좌표와 보드를 유지한다. 실패 — 실패 시 상태 일부가 변경된다.
- [ ] 회전: 통과 — 7종이 확정된 회전 규칙을 따르고 빈 공간에서 네 번 회전 후 원래 형태로 돌아온다. 실패 — 셀 소실·중복·형태 변형 또는 잘못된 회전 중심이 발생한다.
- [ ] 회전 경계값: 통과 — 벽·바닥·고정 셀 주변의 회전 결과가 확정된 취소 또는 보정 정책과 일치한다. 실패 — 충돌하는 회전을 적용하거나 정책과 다르게 위치가 변한다.
- [ ] 고정과 다음 생성: 통과 — 하강 실패 시 마지막 유효 위치에 한 번 고정하고 라인 제거 후 다음 블록을 생성한다. 실패 — 겹침, 이중 고정 또는 처리 순서 오류가 발생한다.
- [ ] 라인 제거: 통과 — 0~4줄 및 떨어진 완성 행을 정확히 제거하고 남은 순서와 20행을 유지한다. 실패 — 행을 건너뛰거나 보드 크기·순서가 바뀐다.
- [ ] 종료 경계: 통과 — 생성 위치가 막힐 때 종료하고 종료 후 입력·시간이 상태를 변경하지 않는다. 실패 — 막힌 생성이 진행되거나 종료 후 상태가 바뀐다.

## 보고 규칙

코드를 직접 고치지 않는다. 체크 결과와 입력 보드·블록 좌표·기대값·실제값 또는 관련 테스트를 근거로 남긴다. 실행하지 못한 검사는 미검증으로 표시한다.

문제는 `항목 | 심각도(높음·중간·낮음) | 개선안` 표로 보고한다. 높음은 보드 손상·핵심 규칙 위반, 중간은 특정 배치에서 발생하는 동작 오류, 낮음은 직접적인 동작 오류가 없는 테스트·명료성 문제다. 문제가 없으면 그 사실과 미검증 범위를 적는다.
