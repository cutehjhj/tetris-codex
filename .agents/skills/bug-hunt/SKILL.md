# 고위험 버그 탐색

## 수행 절차

1. 저장소 지침과 게임 규칙을 확인하고 상태 전환, 시간 처리, 이벤트 등록 및 배열 변경 지점을 찾는다.
2. 아래 위험 사례를 검증하고 재현 순서·환경·기대값·실제값을 수집한다.
3. 확인된 버그와 근거가 부족한 의심 사항을 분리하고 영향 범위와 재현 빈도로 우선순위를 정한다.

## 점검 체크리스트

- [ ] 루프 중복: 통과 — 반복 Restart 후에도 게임 루프가 하나만 동작한다. 실패 — 하강이 빨라지거나 중복 상태 전환이 발생한다.
- [ ] 입력 중복: 통과 — 이벤트 등록·재초기화 후 한 입력이 규칙대로 한 번 처리된다. 실패 — 핸들러 누적으로 이동·회전이 중복 적용된다.
- [ ] 시간·입력 경합: 통과 — 자동 하강 직전·직후 Soft Drop과 회전이 유효 상태를 유지한다. 실패 — 이중 고정·블록 누락·셀 겹침이 발생한다.
- [ ] 상태 참조 공유: 통과 — 보드 행, 블록 원본, 이전 게임과 새 게임이 의도치 않게 공유되지 않는다. 실패 — 한 상태 변경이 다른 상태를 훼손한다.
- [ ] 다중 라인 삭제: 통과 — 인접·비인접 완성 행을 한 번에 제거해 줄 수와 점수가 맞는다. 실패 — 순회 중 삭제로 행을 건너뛰거나 중복 계산한다.
- [ ] 종료·재시작 전환: 통과 — 종료 후 상태가 유지되고 재시작은 타이머와 게임 상태를 초기화한다. 실패 — 이전 콜백이 새 게임을 변경한다.
- [ ] 긴 프레임·탭 복귀: 통과 — 지연 또는 탭 복귀 후에도 유효한 보드와 단일 루프를 유지한다. 실패 — 비정상적인 중복 처리·멈춤·상태 손상이 발생한다.
- [ ] 실행 오류: 통과 — 필수 시나리오에서 처리되지 않은 예외나 필수 리소스 로드 실패가 없다. 실패 — 콘솔 오류와 함께 기능이 깨진다.

## 보고 규칙

코드를 직접 고치지 않는다. 체크 결과와 재현 근거를 기록하며 실행하지 못한 항목은 미검증으로 표시한다. 의심 사항은 확인된 버그로 단정하지 않는다.

문제는 `항목 | 심각도(높음·중간·낮음) | 개선안` 표로 높음부터 정렬한다. 같은 심각도에서는 재현 빈도와 영향 범위가 큰 문제를 먼저 둔다. 높음은 실행 불가·상태 손상·핵심 진행 차단, 중간은 특정 조건의 기능 오류, 낮음은 진행을 막지 않는 결함이다. 항목에 재현 절차와 확인 여부를 포함하며 문제가 없으면 그 사실과 미검증 범위를 적는다.
